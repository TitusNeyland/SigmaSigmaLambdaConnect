# Screen map

Every screen in the design canvas, what it does, and the issues that build it. Canvas (private): https://claude.ai/artifact/HCycq4MqBnbSJsFLUwqacV

All names and figures in the mockups are sample data.

## Navigation

```mermaid
flowchart TD
Tabs[Tab bar] --> Home[Home feed]
Tabs --> Events[Events + Calendar]
Tabs --> Compose[Post: Compose]
Tabs --> Chapter[Chapter hub]
Tabs --> Profile[My profile]
Home --> PostDetail[Post 3: Comments, report, block]
Home --> EventDetail[Event details + RSVP]
Home --> Activity[Activity]
Activity --> PostDetail
Events --> EventDetail
Compose --> PostDetail
Profile --> EditProfile[Edit profile]
Profile --> Settings[Settings]
Chapter --> Directory[Brotherhood directory]
Chapter --> Documents[Documents: committee reports]
Chapter --> Goals[Chapter progress]
Chapter --> Leader[Leadership home, officers only]
Leader --> Health[Chapter health]
Leader --> Attendance[Take attendance]
Leader --> Reports[Review reports]
Leader --> Desktop[Desktop dashboard, later]
```

## Posting flow

Photos: the Post tab opens straight to the camera roll (Recents grid, camera tile first, tap to pick up to 10 in order; picked photos show above it, tap one to edit it or remove it). | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| My profile   | Photo with gold ring, counts for posts, events and service hours, name, headline, initiation, bio, "Works in" industry, "Lives in" city and "Owns" businesses lines, interest tags. Photos tab (square grid, photo posts only), Text tab (posts without photos, each with the member's photo, name and when), Tagged tab (posts others tagged them in) and Activity tab: Coming up (events they RSVP'd Going to), then Recent, newest first (check-ins with service hours, posts shared, posts they were tagged in, initiation and line anniversaries); each event or post row opens it.
